# Giao diện mẫu frontend

Lưu thiết kế và tài liệu tham khảo phục vụ xây dựng giao diện frontend.

## Cách tổ chức khi có tài liệu

- `screen-inventory.md`: các màn hình, mục đích và vai trò được sử dụng.
- `navigation-flows.md`: hành trình người dùng và liên kết giữa các màn hình.
- `design-guidelines.md`: màu sắc, kiểu chữ, khoảng cách, thành phần và quy tắc responsive.
- `design-references.md`: liên kết Figma hoặc nguồn tham khảo, kèm mô tả và trạng thái thiết kế.
- `wireframes/`: bản phác thảo bố cục.
- `mockups/`: bản thiết kế giao diện chi tiết.
- `assets/`: ảnh tham khảo, icon và tài nguyên minh họa.
- `prototypes/`: bản mẫu HTML/CSS hoặc bản demo giao diện nếu có.

Đặt tên thiết kế theo màn hình và kích thước, ví dụ `login-desktop.png`, `login-mobile.png`. Với ảnh tham khảo, ghi rõ nguồn trong `design-references.md`.

Chưa có giao diện mẫu. Các file và thư mục con trên sẽ được bổ sung khi có thiết kế.
