# Tài liệu dự án vCraft

Tài liệu được chia theo nội dung, từ đề bài đến thiết kế giao diện:

| Thư mục | Nội dung |
| --- | --- |
| [01-project-brief](01-project-brief/) | Đề bài gốc, mục tiêu, phạm vi và tiêu chí đánh giá. |
| [02-specifications](02-specifications/) | Yêu cầu chức năng, phi chức năng, vai trò người dùng và quy trình nghiệp vụ. |
| [03-technology](03-technology/) | Công nghệ sử dụng, phiên bản, lý do lựa chọn và hướng dẫn thiết lập môi trường. |
| [04-architecture](04-architecture/) | Kiến trúc hệ thống, các thành phần, cơ sở dữ liệu, API và sơ đồ triển khai. |
| [05-ui-design](05-ui-design/) | Giao diện mẫu frontend, wireframe, mockup, ảnh tham khảo và liên kết thiết kế. |

## Quy ước lưu trữ

- Ưu tiên Markdown (`.md`) cho tài liệu viết trong dự án; giữ nguyên định dạng tài liệu gốc như PDF, DOCX hoặc PPTX.
- Đặt tên file bằng tiếng Anh, viết thường, phân cách bằng dấu gạch ngang, ví dụ `functional-requirements.md`.
- Lưu ảnh và tệp đính kèm trong thư mục `assets/` của từng nhóm khi cần; dùng đường dẫn tương đối để liên kết.
- Cập nhật README của từng nhóm khi bổ sung tài liệu hoặc liên kết ngoài.
- Chỉ ghi công nghệ, yêu cầu và quyết định thiết kế đã được xác nhận; đánh dấu rõ nội dung đang đề xuất.
