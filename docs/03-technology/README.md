# Công nghệ

Lưu danh sách công nghệ và hướng dẫn thiết lập môi trường phát triển.

## Tài liệu dự kiến

- `technology-stack.md`: công nghệ frontend, backend, cơ sở dữ liệu, công cụ và phiên bản.
- `technology-decisions.md`: căn cứ lựa chọn và các phương án đã cân nhắc.
- `environment-setup.md`: yêu cầu cài đặt, cấu hình và cách chạy dự án.

Không lưu mật khẩu, token hoặc khóa bí mật trong tài liệu; chỉ mô tả tên biến cấu hình và giá trị mẫu.

Chưa xác định công nghệ. Các tên file trên là gợi ý khi bổ sung nội dung.
